# Student Management System

A simple Student Management System developed using Python and MySQL to manage student records efficiently.

## 📌 About the Project

The Student Management System is a basic application that helps manage student information.

Users can add, view, update, and delete student records.

This project was developed to practice Python programming and database management using MySQL.

## 🚀 Features

- Add new student
- View student details
- Update student information
- Delete student records
- Store student data in MySQL
- Simple and easy-to-use interface

## 🛠️ Technologies Used

- Python
- MySQL
